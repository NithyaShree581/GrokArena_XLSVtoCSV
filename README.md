\# XLSX to CSV Converter



A Python command-line tool that converts every sheet

in an Excel workbook or Google Sheets document

into individual CSV files.



\## Features



\- Supports local XLSX files.

\- Supports Google Sheets URLs.

\- Converts all worksheets.

\- Creates a separate output directory.

\- Preserves the header row.

\- Handles duplicate sheet names safely.



\## Technologies



\- Python

\- Pandas

\- OpenPyXL

\- Requests
